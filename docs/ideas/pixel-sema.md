# Future Idea: 3D Pixel-Art Sema

Saved for much later (after the core platform, real ZIP plugin architecture, and official plugin separation are complete and rock-solid).

## Concept

Replace the current smooth 3D spherical-eye Bloub Sema with a **cute 3D pixel-art Sema** inspired by the pixel-art semicolon mascot in the Syntax header banner:

- **Form:** True recognizable semicolon silhouette (rounded kawaii pixel face as the top dot, crisp curved pixel comma below).
- **Expression & charm:** Big expressive shiny eyes, subtle pink blush cheeks, crisp pixel-art shading/outline, and animated blinking and idle reactions using pixel-art community animation principles (squash-and-stretch, blink cycles, secondary motion on the comma tail, subtle sparkle accents).
- **Interactive 3D feel:** Draggable, movable, and responsive to cursor/lesson state while preserving razor-sharp nearest-neighbor pixel rendering.
